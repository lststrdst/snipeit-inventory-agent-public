# История версий

## 1.3.3

Я объединил названия компонентов, завершил скрытую установку, добавил
исключения системных пользователей, безопасный offboarding, недельный health
report, retention и устойчивую сортировку IMAP без перемещения посторонней
почты.

## 1.3.2

Исправил сбор RAM: исходные значения SMBIOS показываются как MT/s без
вычисления условных MHz.

## 1.3.0–1.3.1

Добавил резервный SMTP/IMAP relay, HMAC, стабильный `event_id`, локальную
очередь, state schema 3, confidence пользователя и dry-run.

## 1.2.x

Базовый агент, установщик, сбор оборудования и первые сценарии автоматического
обновления активов. Подробные изменения опубликованы в GitHub Releases.
