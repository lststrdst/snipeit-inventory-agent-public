# Тексты GitHub Releases

## v1.3.3 — текущий релиз

Я выпустил `1.3.3`, чтобы превратить инвентаризацию в полный автоматический
жизненный цикл актива, который продолжает работать вне локальной сети.

### Что добавлено

- PowerShell-агент и полностью скрытая установка через GPO;
- прямое обновление Snipe-IT и резервная доставка SMTP/IMAP;
- HMAC-проверка, стабильный `event_id` и защита от дублей;
- безопасное определение владельца без системных учетных записей;
- автоматический возврат техники отключенного пользователя на склад;
- выдержка перед soft delete пользователя;
- weekly health report со статусами свежести данных;
- retention логов, очередей, почтовых папок и SQLite;
- сортировка только точных проектных писем без затрагивания обычного INBOX;
- dry-run, systemd units, материалы GPO и автоматические тесты.

### Проверка

Перед публикацией я выполнил тесты агента, установщика, IMAP relay и maintenance,
проверил синтаксис и отдельно просканировал пакет на секреты и внутренние
идентификаторы.

### Ограничения

Реальные домены, адреса, OU/DN, учетные записи, production JSON, API token,
пароли, HMAC/SSH-ключи, базы и логи не публикуются. В `1.3.3` HMAC подтверждает
целостность, но не шифрует payload, а прямой API token все еще используется на
клиенте. Новую модель без клиентского API-доступа я развиваю в репозитории
`snipeit-inv-mailgateway-public`.

## v1.2.3 — переходный архивный релиз

Я добавил расширенное локальное state, confidence определения пользователя,
dry-run и защиту от неоднозначного checkout. Релиз сохранен для сравнения и
отката; все организационные значения заменены нейтральными примерами.

## v1.2.2 — исправление RAM

Я убрал ошибочный расчет условных MHz. Значения `ConfiguredClockSpeed` и
`Speed` теперь берутся напрямую из SMBIOS и отображаются как MT/s. Распаянная
LPDDR/BGA-память определяется отдельно.

## v1.2.1 — архив базового агента

Промежуточный снимок прямой инвентаризации до появления offline relay: агент,
установщик, сбор оборудования, определение пользователя и обновление актива.

## v1.2.0 — первый архивный пакет

Первый зафиксированный пакет проекта с PowerShell-агентом, установщиком,
launcher и шаблоном конфигурации.
