# Архив версий агента

Здесь находятся исходные наборы предыдущих версий агента для
сравнения и восстановления: `v1.2.0`, `v1.2.1`, `v1.2.2` и `v1.2.3`.

Production-адреса, почта и другие внутренние значения заменены примерами.
Секреты, SSH-ключи, локальные конфиги, логи и резервные ZIP-файлы исключены.
