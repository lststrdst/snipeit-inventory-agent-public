# Production verification: SnipeIT Inventory 1.3.3

Дата повторной проверки: 14.08.2026.

## Решение

Комплект готов к загрузке на DC1 и развёртыванию через существующую GPO. DC1, GPO и клиентские компьютеры во время этой проверки не изменялись.

На сервере Snipe-IT установлен совместимый тихий фикс relay: папка `! Weekly Reports`, сортировка каждые 2 минуты, поддержка новых и старых тем, поиск relay по `X-SnipeIT-Relay: 1` и защита постоянной SQLite от изменений в `Dry Run`.

## Проверки

- 19 PowerShell-файлов разобраны parser без ошибок.
- 6 JSON-файлов успешно разобраны.
- Relay: 42/42 unit-теста успешно.
- Maintenance: 11/11 unit-тестов успешно.
- Все 8 PowerShell test suites завершились с кодом 0.
- Закрытый production JSON прошёл 30 проверок установщика.
- Ручной установщик проверен на UAC, запуск bootstrap от `SYSTEM`, hidden PowerShell, secure share, контроль постоянной задачи и удаление bootstrap.

## Безопасность

- Реальные секреты находятся только в каталогах `*-SECURE`.
- Приватный LDAP SSH-ключ поступает только из secure-шары.
- На клиенте ключ хранится в `C:\ProgramData\snipeit_auto\Config` с ACL для `SYSTEM` и локальных администраторов.
- Старые копии ключа удаляются только после установки и проверки защищённой копии.
- SMTP-пароль и relay HMAC являются разными секретами.
- Агент не создаёт и не перезаписывает теги активов.

## Почта

- Обычная успешная плановая инвентаризация не создаёт человеческое письмо.
- Значимые штатные события попадают в `Reports`.
- Users Deletion и другие серверные действия попадают в `Alerts`.
- Безопасно завершённые ситуации, требующие внимания, попадают в `Warnings`.
- Неисправленная ошибка или relay failure старше 24 часов попадает в `Errors`.
- Offline JSON обрабатывается через `Offline Relay`, `Processed Events` и `Rejected Events`.
- За ISO-неделю формируется ровно одно полное письмо в `! Weekly Reports`: `REPORT` либо `ALERT`.
- Старые `[SNIPEIT-RELAY]`, `[PCINV-REPORT]`, `[PCINV-ALERT]` и `PC Inventory ...` обрабатываются тем же циклом без правил Яндекс.Почты.
- Три ранее зависших relay-события переобработаны: два применены, одно безопасно признано устаревшим относительно более свежей записи Snipe-IT.

## Ограничение развёртывания

Пока файлы 1.3.3 не скопированы на DC1, существующие клиенты продолжают работать на своих старых версиях. Машина, которая не видит DC1 ни напрямую, ни через VPN, обновится при следующем доступе к домену; это ограничение транспорта, а не агента.
